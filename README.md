# Mirae Attestatsiya Android
Android Studio orqali loyiha papkasini oching. JDK 17, Gradle 8.9 va Android SDK 35 bilan Gradle Sync bajaring. Gradle o‘rnatilgan terminalda `gradle assembleDebug` APK yaratadi. Fayl `app/build/outputs/apk/debug/app-debug.apk` manzilida chiqadi. GitHub Actions uchun Android APK workflow ham kiritilgan. ZIP tarkibini repozitoriy ildiziga joylang.
 
Ilova internetsiz ishlaydi. 400 savolli bazani assets ichidan o‘qiydi. Mashqlar tarixi qurilmaning progress.db bazasida saqlanadi. bank400.db shu versiyadagi savollar va kalitlar uchun doimiy nusxa hisoblanadi. Seriya yakunlangan test kunlari bo‘yicha, daraja esa turli savollarga berilgan to‘g‘ri javoblar bo‘yicha hisoblanadi.
